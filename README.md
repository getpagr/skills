# Pagr Skill

[![skills.sh](https://skills.sh/b/getpagr/skills)](https://skills.sh/getpagr/skills) [![smithery badge](https://smithery.ai/badge/getpagr/pagr)](https://smithery.ai/servers/getpagr/pagr)

Install the Pagr skill in your AI coding agent:

```bash
npx skills add getpagr/skills
```

This installs [`SKILL.md`](./SKILL.md) into supported agents (Claude Code, Cursor, Codex, and [50+ more](https://github.com/vercel-labs/skills#supported-agents)).

## What the skill does

Teaches your agent to use the [Pagr CLI](https://github.com/getpagr/pagr) to publish, update, list, and delete HTML files — reports, dashboards, or any document — as shareable public URLs.
